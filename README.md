## 💕 자기 소개
React·Next.js 프런트엔드로 커리어를 시작해, 지금은 Django 모델·쿼리까지 직접 이어 붙이는 풀스택으로 범위를 넓히고 있는 웹 개발자입니다.  
산업 AI 판독 시스템, 숙박 큐레이션 플랫폼, ITS 표준데이터 관리 시스템 세 도메인을 거치며 국제 표준 문서나 엑셀 기능목록처럼 정형화되지 않은 요구사항을 스키마와 화면으로 옮기는 일을 해 왔습니다.  
2021년 4월에 시작해 재직 합계는 약 4년 반입니다.

- **화면이 사용자에게 사실을 말하게 만듭니다.** [같은 데이터를 두 화면이 198건과 134건으로 세고 있으면](https://hyo814-blog.vercel.app/blog/같은-표준데이터를-두-화면이-198건과-134건으로-세고-있었다) 숫자를 맞추기 전에 "무엇을 그 데이터라고 부르는가"부터 정합니다.
